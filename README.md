# List diff

Open `index.html` in a browser. No build, dependencies, or server required.

Compare two lists live, with differences, intersection, and union. Supports text file imports (up to 5 MB), drag and drop, configurable separators and matching, sorting, output formats, copying, and downloads.

Blank items are ignored and results are deduplicated according to the comparison options. Results preserve the first original item (from A for shared items). Delimiter splitting is literal, not a quoted CSV parser. Lists stay in browser memory and are cleared on reload.

`styles.css` is copied from `C:\projects\unixtime`; `listdiff.css` adds the list-specific layout. All assets are local.
